# Data Structure & Graph Performance Analyzer

## CIT300 - Data Structures and Algorithms | Graded Practical Assignment 2

## Project Description
A Java-based console application that demonstrates data structures
(Array, Stack, Queue, Linked List), searching algorithms
(Linear Search and Binary Search), graph representation with
BFS and DFS traversal, and performance comparison using step
counts and execution time.


## Main Features
- Array operations: Insert, Delete, Search, Display
- Stack operations: Push, Pop, Peek, Display
- Queue operations: Enqueue, Dequeue, Peek/Front, Display
- Linked List operations: Insert, Delete, Search, Display
- Linear Search and Binary Search with step counting
- Graph using adjacency list
- Add Vertex and Add Edge
- BFS and DFS traversal
- Performance comparison using steps and execution time
- Input validation
- Empty structure handling
- Integrated console menu
- Display All Results option

## Complexity Summary

| Operation | Complexity |
|---|---|
| Array Insert (end) | O(1) |
| Array Delete | O(n) |
| Array Search | O(n) |
| Stack operations | O(1) |
| Queue operations | O(1) |
| Linked List Insert (tail) | O(n) |
| Linked List Delete | O(n) |
| Linked List Search | O(n) |
| Linear Search | O(n) |
| Binary Search | O(log n) |
| BFS | O(V + E) |
| DFS | O(V + E) |


## How to Run

### 1. Clone the Repository
```bash
git clone https://github.com/Naseebathasim/CIT300-Data-Structure-Graph-Analyzer.git
```

### 2. Go to the `src` folder
```bash
cd CIT300-Data-Structure-Graph-Analyzer/src
```

### 3. Compile all Java files
```bash
javac *.java
```

### 4. Run the program
```bash
java Main
```

### 5. Use the program
Choose an option from the main menu.
